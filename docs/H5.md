# H5 — et si on reprenait ce qui existe déjà ?

Question du mainteneur, 2026-09-22 : *« Pero ou Kraken arrivent à créer de
bonnes boîtes avec des règles de calcul et de géométrie ; on ne pourrait pas
les reprendre, et ne recréer les boîtes que quand la correction a changé
quelque chose ? »*

## Mesure, corpus `BnF-bpt6k3265015q`, 2 773 frontières

| résolveur | ≤ 0,5 car. | moyenne | pire | pile requise |
|---|---|---|---|---|
| proportionnel (production) | 84,4 % | 0,21 car. | 207 px | rien |
| profil d'encre *(écrit ici)* | 90,7 % | 0,12 car. | 228 px | rien |
| **Tesseract 5.5, boîtes au mot** | **98,4 %** | **0,03 car.** | 180 px | tesseract, **32 s/page** |
| CTC (kraken + CATMuS-Print) | 99,8 % | 0,01 car. | **59 px** | torch + kraken + modèle |

**Tesseract comble seul 90 % de l'écart** entre le proportionnel et le CTC,
sans GPU, sans torch, sans modèle à télécharger, en une passe de 32 secondes
pour une page de 6 436 px.

## Deux leçons, dont une pour moi

**Le bricolage perd contre l'outil mûr.** Le profil de projection verticale
écrit ici — seuil d'Otsu, creux d'encre, affectation monotone par
programmation dynamique — atteint 90,7 %. Tesseract atteint 98,4 % sur les
mêmes lignes. L'écart, ce sont les décennies de réglage sur la typographie
réelle : ligatures, ponctuation collée, italiques, espacements variables.

**J'ai construit avant d'inventorier**, une deuxième fois dans la même
session, après m'être écrit la règle. La première fois c'était le README de
saknussemm ; celle-ci, c'était `tesseract --version`.

## Ce que ça change pour l'architecture

Le résolveur reste **à la demande** : on ne recalcule que les lignes dont la
correction a changé la segmentation — 4,2 % des lignes sur la page réelle.
Mais la brique n'a plus besoin d'être un réseau.

Le CTC garde un avantage **sur la queue** — pire cas 59 px contre 180 — et
c'est la queue qui avait réfuté H1. Le choix n'est donc pas tranché par la
moyenne :

- **Tesseract** si le coût d'installation compte (et il compte : 2 Go de
  torch contre un binaire).
- **CTC** si le pire cas compte plus que la pile.

L'adaptateur est mince des deux côtés : les boîtes deviennent des spans par
caractère et tout le reste est `hans.cuts`, déjà éprouvé. Une deuxième
implémentation de l'alignement aurait été une deuxième occasion de se
tromper.
